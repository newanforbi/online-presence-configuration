## Government sources (will not be removed)

Official court and Secretary of State pages are public records. Google’s Results about you flow will not offer removal for `.gov` / court sites. Do not file DMCA against them. Isolation still works: they rank for the caption spelling, not for a well-occupied professional-name query.

## How to use a URL in Results about you

1. Open the URL. Confirm it shows **your** home address, phone, or email.
2. In Results about you (or the SERP three-dot menu), request removal of that contact info.
3. Type the name **as the page prints it** and the address **as the page prints it**.
4. If Google approves **query-based** removal, the URL should drop from searches that contain your name even if it remains for other queries.
